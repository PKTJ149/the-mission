# จุดเด่นระบบมินิเกม + ภารกิจ (สำหรับหน้า Sale)

> **อัปเดต:** 19-11-2026 · ร่างแรก รอทีมยืนยัน
> **ที่มา:** ไล่ดูระบบหลังบ้านมินิเกมและภารกิจทุกหน้า ทุกขั้นตอนการตั้งค่า รายงาน และ script ต้นฉบับ
> (สำเนาใน `backoffice-app/` + ไฟล์ capture ใน `backoffice-reference/`) และหน้าผู้เล่นใน `wallet-app/`
> ไม่ได้แตะระบบ staging จริง

## วิธีอ่านไฟล์นี้

- ทุกข้อมาจากสิ่งที่มีอยู่จริงในระบบ มีตัวเลขกำกับ ไม่มีข้อไหนแต่งขึ้น
- **ยังไม่มีข้อมูลคู่แข่ง** ข้อที่ติด ⭐ คือข้อที่ "น่าจะเป็นจุดต่าง" เพราะลึกหรือแปลกกว่าระบบทั่วไป
  แต่ต้องให้ทีมยืนยันก่อนว่าเจ้าอื่นไม่มี หรือทำได้ไม่เท่า แล้วค่อยเขียนว่า "เหนือกว่า" บนหน้า sale
  (มีตารางให้กรอกในส่วนที่ 5)
- ข้อที่ไม่ติด ⭐ คือความสามารถพื้นฐานที่ควรมีบนหน้า sale แต่ไม่ใช่จุดขายหลัก
- **ส่วนที่ 4 สำคัญมาก:** รวมสิ่งที่ห้ามขาย และข้อความบนหน้า promo ปัจจุบันที่เขียนเกินจริง

## สรุป 1 นาที: 7 เรื่องที่น่าจะเป็นจุดต่างที่สุด

1. **แจกสิทธิ์อัตโนมัติจากยอดฝากจริง** ตั้งกฎได้ 3 รูปแบบการฝาก × 4 กฎยอดฝาก (MG-1)
2. **คุมต้นทุนได้ทุกชั้น** งบรวมทั้งเว็บ, ลิมิตรายคน, สต็อกรางวัลรายช่อง, ติดเทิร์น (MG-2, MG-5, MG-6, MS-5)
3. **กันคนฟาร์มสิทธิ์ในตัว** เช็คยอดเงิน, เพดานถือสิทธิ์, ดึงสิทธิ์คืนเมื่อถอน, หักสิทธิ์ข้ามเกม (MG-3, MG-4)
4. **ภารกิจออกแบบได้ยืดหยุ่น** เรียงลำดับหรือไม่เรียงก็ได้, จบแบบ "ทำครบ N ข้อ", เงื่อนไข 20 แบบ (MS-1, MS-2)
5. **ภารกิจวนรอบเองได้** รอบรายวัน รายสัปดาห์ รายเดือน + รีเซ็ตอัตโนมัติ (MS-3)
6. **มินิเกมกับภารกิจเชื่อมกัน** รางวัลภารกิจคือสิทธิ์เล่นเกม รางวัลเกมคือสิทธิ์เกมอื่น (MG-7, C-1)
7. **รายงานลึกถึงรายคน** พร้อมประวัติการแก้ไขและการยกเลิกที่ตรวจสอบย้อนหลังได้ (MG-14, MS-9, MS-10)

## ส่วนที่ 1: มินิเกม

### ⭐ MG-1 แจกสิทธิ์อัตโนมัติจากยอดฝาก ตั้งกฎได้ละเอียด
- รูปแบบการฝาก 3 แบบ: **ฝากครั้งเดียว**, **ฝากสะสม** (ภายใน N วัน), **ฝากติดต่อกัน** (N ครั้งภายใน N วัน)
- กฎยอดฝาก 4 แบบ: ฝากเท่ากับ, ฝากขั้นต่ำ, ฝากสูงสุด, ช่วงยอดฝาก (จาก–ถึง)
  - ฝากสูงสุดและช่วงยอดฝาก ใช้ได้กับ "ฝากครั้งเดียว" เท่านั้น
- **ได้อะไร:** ไม่ต้องมีแอดมินคอยแจกมือ ลูกค้าฝากถึงเงื่อนไขก็ได้สิทธิ์ทันที
  และออกแบบได้ว่าจะกระตุ้น "ฝากบ่อย" หรือ "ฝากก้อนใหญ่"

### ⭐ MG-2 คุมงบได้ 2 ชั้น: งบรวมทั้งเว็บ + ลิมิตรายคน
- ลิมิตรวมทุกคน: ต่อวัน / ต่อสัปดาห์ / ต่อเดือน / ตลอดอายุโปรโมชั่น
- ลิมิตรายคน: ต่อการฝาก 1 ครั้ง / ต่อวัน / ต่อสัปดาห์ / ต่อเดือน / ตลอดอายุโปรโมชั่น
- ระบบบังคับให้ตัวเลขสอดคล้องกันเอง (วัน ≤ สัปดาห์ ≤ เดือน ≤ ตลอดโปร และลิมิตรายคนต้องไม่เกินลิมิตรวม)
- จำกัดอีกชั้นได้: สมาชิกใช้สิทธิ์ได้ไม่เกิน X สิทธิ์ ต่อ 1 เกม ต่อวัน
- **ได้อะไร:** รู้งบสูงสุดล่วงหน้า ไม่มีวันจ่ายเกินที่ตั้งไว้

### ⭐ MG-3 กันการฟาร์มสิทธิ์ในตัว
- ไม่แจกสิทธิ์ ถ้ายอดเงินก่อนฝากสูงกว่า X บาท
- เพดานถือสิทธิ์: ถ้ามีสิทธิ์ค้างครบ X แล้ว จะไม่แจกเพิ่ม ส่วนที่เกินถูกตัดทิ้ง
- ดึงสิทธิ์คืนเมื่อถอน:
  - ยอดคงเหลือหลังถอนต่ำกว่า X บาท → หัก N สิทธิ์ หรือหักทั้งหมด
  - ยอดถอนน้อยกว่า X บาท → หัก N สิทธิ์ หรือหักทั้งหมด
- **ได้อะไร:** ปิดช่อง "ฝาก → หมุน → ถอน" วนรับของ

### ⭐ MG-4 หักสิทธิ์ข้ามเกม กันสิทธิ์เฟ้อเมื่อเปิดหลายเกมพร้อมกัน
- ตั้งได้ว่า ใช้ 1 สิทธิ์ในเกมนี้ ให้หัก N สิทธิ์จากเกมอื่นด้วย (ตั้งได้หลายเกม)
- ในระบบเขียนเหตุผลไว้ตรง ๆ ว่า "เพื่อไม่ให้สิทธิ์เฟ้อ"
- **ได้อะไร:** เปิดหลายเกมพร้อมกันได้โดยต้นทุนไม่บาน

### ⭐ MG-5 ผูกกับเทิร์นโอเวอร์ครบในตัว
- ติดเทิร์นแบบ **x เท่า** ((ยอดฝาก + โบนัส) × x) หรือ **x บาท**
- ตั้งยอดเทิร์นขั้นต่ำ และจำกัดเวลาทำเทิร์นเป็นชั่วโมงได้
- เลือกได้ว่าจะให้โบนัส **ก่อน** หรือ **หลัง** ทำเทิร์นสำเร็จ
- ลูกค้าที่ยังติดเทิร์นโปรอื่นอยู่ ตั้งได้ 2 แบบ:
  - ให้รับสิทธิ์เมื่อทำเทิร์นโปรเดิมเสร็จ
  - ให้ลูกค้ากดยกเลิกโปรเดิมเพื่อรับสิทธิ์มินิเกมได้

### ⭐ MG-6 คุมต้นทุนรางวัลได้รายช่อง
- ตั้ง **โอกาสออก %** ของแต่ละช่อง
- **จำกัดจำนวนแจก** ต่อช่อง (หรือไม่จำกัด)
- ตั้ง **แจ้งเตือนเมื่อรางวัลใกล้หมด** (ต้องเช็คว่าแจ้งลูกค้าหรือแจ้งแอดมิน ถ้าแจ้งลูกค้าจะใช้เป็นจุดเร่งให้รีบเล่นได้)
- หน้ารวมมินิเกมในหลังบ้านโชว์ตัวนับ "แจกไปแล้วกี่ชิ้น" ของแต่ละช่องแบบสด
- 1 ช่องให้ได้หลายโบนัสพร้อมกัน เลือกได้ 3 แบบ:
  - เครดิต Fixed Rate (จำนวนบาท)
  - เครดิตเป็น % ของยอดฝาก (มีเพดาน "สูงไม่เกิน" X บาท)
  - สิทธิ์มินิเกม

### ⭐ MG-7 รางวัลต่อยอดเป็นสิทธิ์เกมอื่นได้
- ช่องรางวัลให้ "สิทธิ์เล่นเกมอื่น" ได้ เช่น ชนะเกมเลือกกล่อง → ได้สิทธิ์หมุนวงล้อ
- **ได้อะไร:** สร้างลูปให้ลูกค้าเล่นต่อเนื่อง

### ⭐ MG-8 สิทธิ์หมดอายุได้ 3 แบบ สร้างความเร่งด่วน
- หมดพร้อมเกม / รีเซ็ตทุกวันตามเวลาที่ตั้ง / นับถอยหลัง วัน:ชั่วโมง:นาที หลังได้รับสิทธิ์
- แสดง **นับถอยหลังหมดอายุเกม** ให้ลูกค้าเห็นได้ เริ่มนับทันทีที่สร้างเกม หรือเริ่มเมื่อเหลือ X วัน / ถึงวันเวลาที่ตั้ง
- ในระบบเขียนจุดประสงค์ไว้ว่า กระตุ้นให้สมาชิกอยากฝากก่อนจะหมดอายุ

### MG-9 ตั้งเวลาเปิดเกมได้ละเอียด
- กำหนดช่วงวันที่ (อายุเกม) หรือไม่กำหนดก็ได้
- เลือกวันที่เปิด (อา–ส) หรือใช้ preset: วันธรรมดา / เสาร์-อาทิตย์ / ทุกวัน
- หลายช่วงเวลาต่อวัน เช่น 12:00–14:00 และ 20:00–23:00

### MG-10 เลือกกลุ่มเป้าหมาย
- เลือกกลุ่มลูกค้าได้หลายกลุ่ม + ซ่อนเกมจากกลุ่มอื่น
- กำหนด Agent (เว็บ) ที่ใช้เกมนี้
- จำกัดค่ายเกม 4 หมวด: กีฬา / เกม / คาสิโน / หวย (ผลที่เกิดจริงตอนใช้งานยังไม่ชัด ต้องเช็คก่อนขาย)

### ⭐ MG-11 แบรนด์ได้เต็มที่ ไม่ต้องหน้าตาเหมือนเว็บอื่น
- ปรับสีได้ **28 จุด** รองรับสีไล่ระดับ (gradient)
- พื้นหลังแยกตามอุปกรณ์: Mobile (430×932) / Desktop (1920×1080) และพื้นที่เกมแยกอุปกรณ์อีกชั้น
- เปลี่ยนรูปได้ทุกส่วน: กรอบวงล้อ, ปุ่มหมุน, popup ตอนชนะ, รูปของทุกช่อง
- มีไฟล์ template ให้ดาวน์โหลดไปทำรูปวงล้อ
- เห็น preview วงล้อสด ๆ ระหว่างตั้งค่า

### ⭐ MG-12 เครื่องมือเดียว ได้หลายหน้าตาเกม
- **วงล้อ** 6 / 8 / 10 ช่อง
- **เกมเลือก** 3 / 6 / 9 ตัวเลือก
  - รูป 3 ขั้น: ก่อนเลือก / หลังเลือก / ผลลัพธ์ ข้ามขั้นที่ 2 ได้
  - ใช้รูปเหมือนกันทุกตัวเลือก หรือต่างกันก็ได้ และสลับลำดับแบบสุ่มได้
  - จึงทำเป็นกล่องสุ่ม เปิดไพ่ หรือธีมอื่นตามเทศกาลได้ จากรูปที่อัปโหลด
- เปิดหลายเกมพร้อมกัน แต่ละเกมมีกติกาของตัวเอง
- ลากเรียงลำดับเกมที่แสดงบนหน้าเล่นได้

### MG-13 รองรับ 3 ภาษา
- ไทย / อังกฤษ / ตากาล็อก สำหรับชื่อเกมและเงื่อนไข (คำอธิบายรางวัลยังเป็นภาษาเดียว)

### ⭐ MG-14 รายงานแบบ funnel ลงลึกถึงรายคน
- สรุปรายเกม: คนมีสิทธิ์ → คนที่รับ → สิทธิ์ทั้งหมด → สิทธิ์ที่ใช้ไป
  พร้อมยอดที่จ่ายออก: เครดิต / สิทธิ์มินิเกม / สิทธิ์หวย / แต้ม / ของรางวัล
- เจาะดูรายเกม → รายคน กรองได้ตามสถานะ / Agent / ประเภท / ผู้ทำรายการ
- อัปเดตอัตโนมัติทุก 30 / 45 / 60 / 120 วินาที
- ประวัติการรับและใช้สิทธิ์ของทุกเกม

### MG-15 เครื่องมือแอดมิน
- แจกสิทธิ์แบบ Manual พร้อมใส่ **"ยอดฝากจำลอง"** (ไม่เติมเงินจริง) เพื่อให้ระบบคำนวณรางวัลและเทิร์นเหมือนลูกค้าฝากจริง
- ยกเลิกสิทธิ์ต้องใส่เหตุผล และย้อนกลับไม่ได้ จึงตรวจสอบย้อนหลังได้

## ส่วนที่ 2: ภารกิจ

### ⭐ MS-1 ออกแบบเส้นทางภารกิจได้ยืดหยุ่น
- ภารกิจหลัก 1 อัน + ภารกิจย่อยกี่ข้อก็ได้ (ไม่พบเพดานในหน้าตั้งค่า)
- ทำแบบ **เรียงลำดับ** (ปลดล็อกทีละข้อ) หรือ **ไม่เรียงลำดับ** (ทำข้อไหนก่อนก็ได้)
- จบภารกิจได้ 2 แบบ: **ทำครบทุกข้อ** หรือ **ทำสำเร็จ N ข้อ** จากทั้งหมด
- ภารกิจย่อย 1 ข้อ ใส่ได้หลายเงื่อนไข
- ภารกิจเดี่ยว = ภารกิจที่มีภารกิจย่อยข้อเดียว

### ⭐ MS-2 คลังเงื่อนไข 5 ประเภท รวม 20 แบบ
- **การฝาก (5):** ฝากเท่ากับ / มากกว่า / ขั้นต่ำ (+ จำนวนครั้ง), ฝากสะสมครบ X บาท, ทุก ๆ X บาทที่ฝาก
- **เทิร์นโอเวอร์ (6):** เท่ากับ / มากกว่า / ขั้นต่ำ / ทุก ๆ ยอดเทิร์น / สะสม, ทำเทิร์นติดต่อกัน X ครั้ง
- **Login เช็คอิน (2):** Login ครบ X วัน, Login ติดต่อกัน X วัน
- **แนะนำเพื่อน (6):** จำนวนเพื่อนเท่ากับ / มากกว่า / ขั้นต่ำ X คน, เพื่อนที่แนะนำแล้วฝาก X คน,
  ยอดฝากรวมของเพื่อน, ทุก ๆ X บาทที่เพื่อนฝาก
- **สะสมแต้ม (1):** ครบ X แต้ม
- เลือกนับเทิร์นเฉพาะประเภทเกมหรือค่ายที่กำหนดได้ (กีฬา / เกม / คาสิโน / หวย, staging มี 64 ค่าย)
- **ได้อะไร:** ใช้ภารกิจดันค่ายเกมที่อยากโปรโมท หรือดันเพื่อนชวนเพื่อนที่ "ฝากจริง" ไม่ใช่แค่สมัคร

### ⭐ MS-3 ภารกิจวนรอบเองได้
- รอบการทำภารกิจ: ทุกวัน / ทุกสัปดาห์ (เลือกวัน) / ทุกเดือน (วันที่ 1–31 + "วันสุดท้ายของเดือน") / กำหนดเอง
- แต่ละรอบเลือกช่วงเวลา หรือทั้งวัน และมีได้หลายรอบ
- **รีเซ็ตภารกิจอัตโนมัติ** เมื่อครบรอบ
- ภารกิจย่อยรับซ้ำได้ทันทีที่ทำสำเร็จ แบบไม่จำกัด หรือจำกัดสูงสุด N ครั้ง
- **ได้อะไร:** ตั้งครั้งเดียว ได้กิจกรรมประจำวันหรือประจำสัปดาห์ไปเรื่อย ๆ

### ⭐ MS-4 รางวัล 2 ชั้น 5 ประเภท
- ให้รางวัลได้ทั้งภารกิจหลักและภารกิจย่อยทุกข้อ ชั้นละหลายรางวัล
- 5 ประเภท: **เครดิต**, **สิทธิ์มินิเกม** (เลือกเกมของเว็บเอง), **สิทธิ์โปรโมชั่น**, **แต้มสะสม**, **ของรางวัล** (ตั้งชื่อเอง)
- เลือกได้ว่า **ลูกค้ากดรับเอง** หรือ **ระบบให้อัตโนมัติ** แยกตั้งได้ทุกชั้น

### ⭐ MS-5 คุมต้นทุนด้วยการติดเทิร์นรางวัล
- ติดเทิร์นขั้นต่ำ x บาท หรือ x เท่า (x เท่า ใช้ได้กับภารกิจหลักที่มีรางวัลเป็นเครดิต)
- จำกัดจำนวนครั้งที่รับรางวัลซ้ำได้

### ⭐ MS-6 เลือกกลุ่มเป้าหมายได้ละเอียด
- เลือกตาม **กลุ่มสมาชิก**, **อายุการใช้งาน** (วัน / สัปดาห์ / เดือน / ปี), **วันที่สมัคร** (ก่อน / หลัง / ระหว่างวันที่)
  - ทำภารกิจต้อนรับสมาชิกใหม่ หรือภารกิจดึงลูกค้าเก่ากลับมาได้
- ซ่อนภารกิจจากคนที่ไม่มีสิทธิ์ทำได้
- แยกตาม Agent: เปิด/ปิดภารกิจราย Agent และเปลี่ยนไอคอนเมนูราย Agent ได้

### ⭐ MS-7 เครื่องมือดึงคนกลับมาทำภารกิจ
- **Pop Up แจ้งเตือน** ตอนเข้าสู่ระบบ
- **ปุ่มลอย** (Floating Action Button) บนหน้าจอ ลูกค้าย้ายหรือปิดได้ และกลับมาใหม่เมื่อเข้าระบบครั้งถัดไป
- ทั้ง 2 แบบตั้งได้ทั้งภารกิจหลักและภารกิจย่อย
- **แบนเนอร์ภารกิจ** หลายอัน สไลด์อัตโนมัติ ลากเรียงได้ ลิงก์ไปเมนู ไปภารกิจที่ต้องการ หรือไป URL ได้
- เปิด/ปิดการแสดงนับถอยหลังให้ลูกค้าเห็น

### MS-8 แต่งหน้าตาได้โดยไม่ต้องมีดีไซเนอร์
- รูปปกภารกิจ: อัปโหลดเอง หรือเลือกจากคลัง 34 รูป
- ไอคอนรางวัลและภารกิจย่อย: คลัง 80 ไอคอน 12 หมวด
- สีพื้นหลัง / ปุ่ม (gradient ได้) และสีตัวอักษร ตั้งแยกรายภารกิจ
- ชื่อภารกิจและเงื่อนไข 3 ภาษา ไทย / อังกฤษ / ตากาล็อก (ชื่อและรายละเอียดภารกิจย่อยยังเป็นภาษาเดียว)

### ⭐ MS-9 แก้ไขได้อย่างปลอดภัย
- คัดลอกการตั้งค่าจากภารกิจอื่นมาใช้ได้
- แก้ไขภารกิจแล้ว ไม่รีเซ็ตความคืบหน้าของสมาชิกที่ทำค้างอยู่ (ตามข้อความยืนยันในระบบ)
- **ประวัติการแก้ไขระดับช่องข้อมูล:** ใครแก้ แก้อะไร เมื่อไร

### ⭐ MS-10 รายงานลึก
- ดูได้ทั้งรายสมาชิก และรายภารกิจ (ภารกิจหลัก + ภารกิจย่อยเรียงกัน)
- แยกรางวัล 5 ประเภท แยกที่มา (Auto / Manual / Complete) และผู้ทำรายการ
- เจาะดูรายสมาชิก มีแถวรวมยอด
- เก็บประวัติของภารกิจที่หมดอายุหรือถูกลบไว้ด้วย

### MS-11 แต้มสะสม + แลกรางวัล
- ลูกค้าได้แต้มจากภารกิจ
- ตั้งเงื่อนไขการแลกได้ 3 ภาษา
- แอดมินแลกให้ลูกค้า โดยระบบเช็คแต้มคงเหลือ และเก็บประวัติ (แต้มก่อน / ใช้ไป / คงเหลือ)
- หมายเหตุ: ยังไม่มีแคตตาล็อกให้ลูกค้าแลกเอง

### MS-12 แจกรางวัล Manual
- ค้นหาสมาชิก เลือกภารกิจหรือภารกิจย่อย แล้วระบบให้รางวัลตามการตั้งค่าของภารกิจนั้น

## ส่วนที่ 3: จุดแข็งเมื่อใช้คู่กัน

### ⭐ C-1 ภารกิจกับมินิเกมเชื่อมถึงกัน
- รางวัลภารกิจให้ "สิทธิ์เล่นมินิเกม" ที่เลือกได้ และรางวัลมินิเกมให้สิทธิ์เกมอื่นได้
- ภารกิจพาคนไปเล่นเกม เกมพาคนไปฝาก

### ⭐ C-2 อยู่ในระบบ AUTO FAST ที่ลูกค้าใช้อยู่แล้ว
- เปิดจากเมนูในหลังบ้านเดิม และใช้ข้อมูลยอดฝาก เทิร์น กลุ่มลูกค้า และ Agent ของเว็บเดียวกัน
- **ต้องยืนยัน:** เปิดใช้ได้ทันทีโดยไม่ต้องเชื่อมระบบเพิ่มจริงไหม (ถ้าจริง นี่คือจุดขายที่แรงมากสำหรับลูกค้าเดิม)

### C-3 ตอบเป้าธุรกิจ 3 ข้อ (ใช้จัดโครงหน้า sale ได้)
- **เพิ่มยอดฝาก:** MG-1, MG-5, MS-2
- **ดึงลูกค้ากลับมาทุกวัน:** MS-3, MS-7, MG-8
- **หาลูกค้าใหม่:** MS-2 (เงื่อนไขแนะนำเพื่อนที่ฝากจริง), MS-6 (ภารกิจสมาชิกใหม่)

### 4.2 มีในระบบ แต่ถูกซ่อน หรือใช้งานไม่ได้
- **มินิเกม:** เสียงตอนหมุน, ให้ทดลองเล่นเมื่อไม่มีสิทธิ์, ซ่อนช่วงโปรบนหน้าเล่น, บล็อกการเล่นเมื่อยอดเงินต่ำ,
  เงื่อนไขการถอน / หลุดโปร / เพิ่มทุน (ขั้นตอนที่ 5), รางวัลแบบแต้ม / สิทธิ์หวย / ของรางวัล
- **ภารกิจ:** เงื่อนไขวันที่สมัครในภารกิจย่อย

### 4.3 ข้อจำกัดที่ควรรู้ (อย่าโฆษณาว่ามี)
- **มินิเกม:**
  - ลบหรือคัดลอกเกมไม่ได้
  - export รายงานไม่ได้
  - ระบบไม่เช็คว่า % โอกาสออกของทุกช่องรวมกันได้ 100%
  - การแก้ไขเกมอาจสร้างเกมซ้ำขึ้นมาใหม่ (ยังไม่ยืนยัน ต้องเช็คก่อน demo การแก้ไข)
- **ภารกิจ:** การแลกแต้มต้องให้แอดมินทำ ลูกค้าแลกเองไม่ได้
- **ทั้งคู่:** "3 ภาษา" ครอบคลุมแค่ชื่อและเงื่อนไข ไม่ใช่ทุกข้อความ

### 4.4 demo ภารกิจบนหน้า sale (iframe ของ wallet-app) ยังไม่แสดงฟีเจอร์เหล่านี้
- ล็อกภารกิจย่อยตามลำดับ, รับรางวัลอัตโนมัติ, จบแบบ N ข้อ, หลายภาษา, Pop Up / ปุ่มลอย, ลิงก์บนแบนเนอร์
- ถ้าจะชูข้อเหล่านี้บนหน้า sale ต้องทำ demo เพิ่ม หรือใช้ภาพจากระบบจริง
