# Audit ระบบตั้งค่าหลังบ้าน: คำ หัวข้อ และตรรกะ

**วันที่:** 20-11-2026
**แอป:** `backoffice-app` (พอร์ต 3100)
**ขอบเขต:** ตั้งค่ามินิเกมส์ (หน้ารายการ + wizard สร้าง/แก้ไข 6 ขั้นตอน) และตั้งค่าภารกิจ (หน้ารายการ + ฟอร์มสร้าง/แก้ไข)
**ตรวจเรื่อง:** คำ หัวข้อ ข้อความ error และตรรกะของฟอร์ม ไม่ได้ตรวจหน้าตา ความเหมือนต้นฉบับระดับพิกเซล และ accessibility (ความเหมือนระดับพิกเซลตรวจไปแล้วใน `AUDIT-2026-11-15-SUMMARY.md`)
**สถานะ:** เป็นรายงานอย่างเดียว ยังไม่ได้แก้อะไรเลย

## วิธีอ่านรายงานนี้

ทุกข้อมี **ระดับความรุนแรง** และ **ที่มา**

| ระดับ | ความหมาย |
|---|---|
| **P0** | แสดงหรือบันทึกข้อมูลผิด ต้องแก้ก่อน |
| **P1** | คำ ข้อความ หรือกฎที่ทำให้แอดมินตั้งค่าผิด หรือทำให้บันทึกไม่ได้ |
| **P2** | สับสนหรือไม่สม่ำเสมอ แต่ยังมีทางเลี่ยง |
| **P3** | เก็บรายละเอียด: คำผิด คำแปลอังกฤษ ความสม่ำเสมอของคำ |

| ที่มา | ความหมาย | ใครตัดสินใจ |
|---|---|---|
| **ของเรา** | rebuild ของเราทำต่างจากต้นฉบับ หรือขาดสิ่งที่ต้นฉบับทำ | แก้ได้เลย ไม่ต้องรอใคร |
| **ต้นฉบับ** | ระบบเดิมก็ผิดแบบนี้ (เจอใน `scriptminigame.js` / `scriptmission.js`, `th.json` หรือ HTML ที่ capture ไว้) เราลอกมาตามกฎ | PK ตัดสินทีละข้อ เพราะถ้าแก้จะผิดกฎ "ลอกต้นฉบับให้เหมือน" |
| **ไม่แน่ใจ** | พิสูจน์จากไฟล์ที่มีไม่ได้ว่าเป็นแบบไหน | ถาม PK |

**วิธีตรวจ** ผู้ช่วย 4 ตัวอ่านโค้ดคนละส่วนแบบอ่านอย่างเดียว เทียบกับโค้ด jQuery ต้นฉบับ `th.json`/`en.json` และหน้าที่ capture ไว้ จากนั้นเช็กซ้ำด้วยมือทุกข้อ P0 ทุกข้อที่เป็น "ของเรา" และ P1 ข้อหลัก

## สรุป

| | P0 | P1 | P2 | P3 | รวม |
|---|---|---|---|---|---|
| **ของเรา** (แก้ได้เลย) | 2 | 2 | 4 | 3 | **11** |
| **ต้นฉบับ** — มินิเกมส์ | 0 | 7 | 35 | 7 | **49** |
| **ต้นฉบับ** — ภารกิจ | 0 | 8 | 15 | 4 | **27** |
| **รวม** | **2** | **17** | **54** | **14** | **87** |

ตัวเลขนับตามแถวในตาราง กลุ่มคำผิด คำแปลอังกฤษ และคำไม่สม่ำเสมอใน P3 นับเป็น 1 ข้อต่อกลุ่ม

**5 เรื่องที่สำคัญที่สุด**

1. **หน้าสรุปขั้นตอน 6 แสดงข้อมูลผิด (ของเรา, P0)** แถวกลุ่มลูกค้าขึ้น 3 กลุ่มปลอม ("New Customer / Commander / VIP") ตลอด และแถว "มินิเกมส์ที่หักสิทธิ์" ไม่มีชื่อเกม
2. **บันทึกมินิเกมแล้วค่าหาย (ของเรา, P1)** ตอนบันทึกไม่อ่านประเภทยอดฝากจากขั้นตอน 3 และบันทึกลิมิตรางวัลทุกช่องเป็น 0
3. **ฟอร์มภารกิจบันทึกไม่ได้ แต่ไม่บอกว่าผิดตรงไหน (ต้นฉบับ, P1)** หลายช่องไม่เคยแสดง error (คือข้อที่มีคอมเมนต์ "ORIGINAL BUG (kept on purpose)") แอดมินเห็นแค่ "ทำรายการไม่สำเร็จ ! / กรุณาตรวจสอบข้อมูลภารกิจของคุณ"
4. **คำหรือ error ที่เป็นของช่องอื่น (ต้นฉบับ, P1–P2)** เกิดจากก๊อป key ข้ามช่อง เช่น error ชื่อภารกิจย่อยบอกให้กรอก*ชื่อของรางวัล* error ประเภทโบนัสบอกให้เลือก*ประเภทการฝาก* และมีส่วนหนึ่งที่หัวข้อกับตัวเลือกทั้ง 2 อันใช้คำเดียวกัน
5. **ขาดการตรวจค่า ทำให้ข้อมูลผิดผ่านไปได้ (ต้นฉบับ, P1)** เวลาสิ้นสุดก่อนเวลาเริ่มได้ ช่วงวันที่ว่างได้ โอกาสออกรวมกันไม่ต้องได้ 100% เปิดตรวจยอด Balance โดยไม่ใส่ยอดได้

**สิ่งที่ PK ต้องตัดสินใจก่อนแก้** (ดูหัวข้อสุดท้าย): นโยบายเรื่อง bug ต้นฉบับ, คำมาตรฐาน และหน้าสรุปควรแสดงแค่ไหน

## ทำไมถึงเกิดซ้ำๆ

1. **Copy-paste key คำแปลข้ามช่อง** เป็นต้นเหตุใหญ่ที่สุด ก๊อปบล็อกมาแล้วไม่ได้เปลี่ยน key คำหรือ error เลยไปบอกเรื่องของช่องข้างๆ (ชื่อรางวัลกับชื่อภารกิจย่อย, ประเภทการฝากกับประเภทโบนัส, วงล้อกับมินิเกม) ซึ่งเป็นแบบเดียวกับเรื่องชื่อสีที่แก้ไปวันนี้
