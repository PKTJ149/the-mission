3. ตั้งค่าภารกิจย่อยที่ N (repeater; `addTemplateSubMission()` button เพิ่มภารกิจย่อย; template `#templateSubMission` not captured separately because it equals sub-mission 1) — icon upload, name, CKEditor description, condition repeater: เงื่อนไข = การฝาก (ฝากเท่ากับ/มากกว่า/ขั้นต่ำ/สะสม/ทุก ๆ ยอดฝาก + amount/count), ทำเทิร์นโอเวอร์ (เท่ากับ/มากกว่า/ขั้นต่ำ/ติดต่อกัน/ทุก ๆ/สะสม + "กำหนดเฉพาะเกม" → `chooseGameType` → `#popup-game-type`), Login (ครบ/ติดต่อกัน + วัน), การแนะนำเพื่อน (6 types), สะสมแต้ม; reward switch with receive type, reset-reward switch (+limit), reward repeater, turnover, notification.
4. ตั้งค่าการเสร็จสิ้นภารกิจ — all / some (+count) radios, reset sub-mission switch.
